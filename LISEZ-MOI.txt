==================================================
              DAWGER - GUIDE RAPIDE
==================================================

PREMIERE INSTALLATION SUR UN NOUVEAU PC :
Double-clique sur "setup-new-pc.bat"
(Installe automatiquement Git, Docker Desktop et Node.js,
demarre Docker et lance Dawger PC).

AU QUOTIDIEN :
Double-clique simplement sur "PC Dawger.bat"
(Lance automatiquement Docker Desktop s'il est ferme,
demarre les conteneurs et ouvre l'application Dawger PC !).

==================================================
SI DOCKER DEMANDE WSL OU LA VIRTUALISATION :
==================================================
Ouvre PowerShell (clic droit -> Executer en administrateur)
et tape ces 2 commandes :

  1. wsl --install --no-distribution
  2. wsl --update

(Redemarre ton PC si Windows le demande).

Note : Si Docker indique que la virtualisation est
desactivee, active "Intel Virtualization (VT-x)" ou
"AMD SVM" dans le BIOS de ton PC au demarrage.
